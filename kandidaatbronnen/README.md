# Kandidaatbronnen

Deze map bevat openbare ecologische gegevens die mogelijk relevant zijn voor
Meijendel, maar nog niet in de levende database mogen worden opgenomen.

Een kandidaatbron wordt pas toegelaten wanneer per waarneming aantoonbaar is
dat zij daadwerkelijk binnen Meijendel is gedaan en de locatie beschikbaar is
of betrouwbaar kan worden herleid. De bestanden in deze map zijn dus geen
onderdeel van de analyse- of importketen.

## Opgenomen kandidaatbronnen

- `jachtspinnen_1969_1970`: gereduceerde openbare matrix van het historische
  jachtspinonderzoek; de 28 locatienummers zijn nog niet geografisch herleid.
