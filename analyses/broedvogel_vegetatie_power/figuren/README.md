# Figuren

Hier komen uitsluitend definitieve figuren voor inhoudelijke beoordeling en
eventueel het artikel. Iedere figuur heeft:

- een stabiele figuurcode;
- een onderschrift dat populatie, periode en eenheid noemt;
- een verwijzing naar het uitvoer-ID, resultaatbestand en generatiescript;
- zichtbare onzekerheid waar die kan worden berekend;
- een aanduiding wanneer een patroon beschrijvend of verkennend is.

Handmatig gewijzigde grafieken zonder reproduceerbare gegevensbasis worden
niet als definitieve figuur bewaard.
